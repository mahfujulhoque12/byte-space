# React + TypeScript + Vite

A modern and fully responsive web application built with **React, TypeScript, and Vite**. The project follows a clean and reusable component-based architecture with custom CSS classes and responsive layouts for all screen sizes.

## 🚀 Tech Stack

* React
* TypeScript
* Vite
* React Router
* Custom CSS
* ESLint / Oxlint

## ✨ Features

* ⚡ Fast development with Vite and HMR
* ⚛️ React with TypeScript
* 📱 Fully responsive design
* 🎨 Custom CSS classes
* 🧩 Reusable components
* ♻️ Clean and modular code structure
* 🖥️ Responsive layouts for desktop, tablet, and mobile
* 🔄 Client-side routing
* 🛡️ Type-safe development with TypeScript
* 🧹 Code quality and linting
* 📦 Production-ready build

## 📱 Responsive Design

The application is designed to provide a consistent and smooth experience across different screen sizes.

The UI is fully responsive for:

* Mobile devices
* Tablets
* Laptops
* Desktop screens
* Large displays

Responsive CSS classes and media queries are used to adapt layouts, spacing, typography, and components according to the screen size.

## 🎨 Styling

This project uses **custom CSS classes** instead of depending completely on a UI framework.

The styling approach focuses on:

* Custom CSS classes
* Reusable styles
* Responsive breakpoints
* Flexible layouts
* Consistent spacing
* Custom typography
* Reusable buttons and form elements
* Maintainable component-specific styles

This approach provides better control over the design and makes it easier to implement custom UI designs.

## 🧩 Component Architecture

The project follows a reusable and modular React component structure.

```text
src/
├── assets/
├── components/
│   ├── common/
│   ├── header/
│   ├── footer/
│   └── ...
├── pages/
│   ├── Home/
│   ├── About/
│   ├── Contact/
│   └── ...
├── routes/
├── hooks/
├── utils/
├── types/
├── App.tsx
├── main.tsx
└── index.css
```

Components are organized based on their responsibilities to keep the project clean, scalable, and easy to maintain.

## 🛠️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Go to the project directory:

```bash
cd <project-name>
```

Install dependencies:

```bash
npm install
```

## ▶️ Run the Development Server

Start the development server:

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 🔍 Linting

Run the linting command:

```bash
npm run lint
```

Linting helps maintain clean, consistent, and reliable code throughout the project.

## 📦 Production Build

After running:

```bash
npm run build
```

Vite generates the optimized production files inside the:

```text
dist/
```

directory.

## 📌 Development Principles

The project follows these development principles:

* **Reusable Components** — Build reusable UI components instead of duplicating code.
* **Responsive Design** — Ensure every section works properly across different screen sizes.
* **Type Safety** — Use TypeScript to improve code reliability and maintainability.
* **Clean Code** — Keep components simple, readable, and focused.

* **Maintainability** — Keep the codebase easy to understand and extend.
